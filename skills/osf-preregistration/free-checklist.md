# Free OSF Pre-Registration Checklist

Use this quick checklist before submitting or sharing a pre-registration draft.

## Status

- [ ] Data collection has not started, or the document is clearly labeled retrospective.
- [ ] The study title is specific.
- [ ] The research question is stated in one clear sentence.

## Hypotheses

- [ ] Confirmatory hypotheses are separated from exploratory analyses.
- [ ] Each hypothesis is falsifiable.
- [ ] Each hypothesis names the variables involved.
- [ ] Predictions include direction, threshold, or expected pattern where possible.

## Variables

- [ ] Primary outcome is defined.
- [ ] Secondary outcomes are defined.
- [ ] Independent variables / predictors are defined.
- [ ] Covariates and controls are listed.
- [ ] Operational definitions are measurable.

## Methods

- [ ] Study design is clear.
- [ ] Population or dataset is defined.
- [ ] Procedure is described.
- [ ] Inclusion / exclusion criteria are defined before analysis.
- [ ] Missing data handling is described.

## Analysis

- [ ] Primary analysis is named.
- [ ] Secondary analyses are named.
- [ ] Exploratory analyses are labeled exploratory.
- [ ] Multiple comparisons handling is described if relevant.
- [ ] Robustness checks are listed where useful.

## Bias reduction

- [ ] Blinding is described or marked not applicable.
- [ ] Randomization is described or marked not applicable.
- [ ] Stopping rules are defined.
- [ ] Deviations will be logged.

## Final review

- [ ] All TBD items are resolved or clearly marked.
- [ ] The plan is specific enough for another researcher to follow.
- [ ] A qualified reviewer, supervisor, statistician, IRB, or ethics body will review it when relevant.
